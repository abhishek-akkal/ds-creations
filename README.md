# DS Creations

A simple and elegant handmade creations website for **DS Creations**.

The website showcases handmade products, spiritual art, wall décor, crochet creations, gifts, and other handcrafted items.

## 🌐 Live Website

👉 **https://ds-creations.vercel.app/**

## ✨ Features

- 🏠 Clean and elegant homepage
- 🛍️ Handmade product collection
- 🎨 Category-based product filtering
- 🧶 Crochet creations
- 🕉️ Spiritual and devotional artwork
- 🏡 Handmade wall décor
- 🎁 Gift creations
- 📱 Responsive design
- 🔗 Instagram and social media links
- 🖼️ Custom brand logo and favicon
